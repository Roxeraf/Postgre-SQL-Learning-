Einrichten

Claude Desktop

  1. Windows-Setup und der erste App-Start tragen learnsql automatisch ein — unabhängig davon, ob Claude schon offen ist.
  2. Falls der Server fehlt: Settings → Developer → Edit Config, Block learnsql einfügen, andere Server lassen.
  3. Claude komplett beenden und neu starten.

Wenn der Server nicht erscheint: dieselbe Datei zusätzlich nach %LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude\claude_desktop_config.json.

Claude Code

Das Windows-Paket schreibt denselben Block nach %USERPROFILE%\.claude.json (Benutzer-weit). Claude Code danach neu starten.

claude mcp add --scope user --transport stdio learnsql -- python mcp/learnsql_mcp.py

Im Windows-Paket die festen Pfade aus der MCP-Anleitung nutzen, nicht das System-python.
