Was du damit machst

Sag Claude einen dieser Sätze. Danach erscheint eine Karte auf dieser Seite.

  • Bau mir drei Werkstatt-Übungen zu offenen Aufträgen mit GROUP BY.
  • Eine LEFT-JOIN-Übung, bei der 4730 ohne Kunde sichtbar bleibt.
  • Prüf die Musterlösung mit run_sql, dann speichern.

plx.learnSQL (oder Docker) muss laufen, bevor Claude SQL prüft. Nachschlagen und Speichern geht auch ohne Datenbank.

Claude Desktop

  1. Windows-Setup: Haken „MCP in Claude Desktop einrichten“, wenn Claude gefunden wurde.
  2. Oder: Settings → Developer → Edit Config, Block learnsql einfügen, andere Server lassen.
  3. Claude komplett beenden und neu starten.

Wenn der Server nicht erscheint: dieselbe Datei zusätzlich nach %LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude\claude_desktop_config.json.

Claude Code

claude mcp add --scope user --transport stdio learnsql -- python mcp/learnsql_mcp.py

Oder denselben Block in %USERPROFILE%\.claude.json. Im Windows-Paket die festen Pfade aus der MCP-Anleitung nutzen.
